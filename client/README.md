# Shared Space - Frontend Client

React-based collaborative workspace with real-time features.

## Tech Stack
- React + Vite
- Socket.IO Client
- Tailwind CSS
- WebRTC for video/audio calls

## Environment Variables
- `VITE_SOCKET_URL` - Backend WebSocket server URL (required)

## Local Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
npm start
```
